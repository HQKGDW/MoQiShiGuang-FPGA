# 默契食光 · 交互端（前台点餐与多媒体展示）

全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道 · 选题一
平台：HX4S20C 开发板（安路 EG4S20BG256），HDMI 1280×720@60 音视频输出。

本工程是双板系统的交互端：顾客通过图文菜单无声点餐，订单经千兆网口直连发到后厨控制端
（工程 `Official_Project_Upper_Computer`）；后厨下发售罄、广告、标语与订单进度字幕。
所有图片、音乐都从 TF 卡读取，全部逻辑在 FPGA 内实现，无额外处理器。

## 功能一览

- TF 卡（SPI 模式）FAT32 文件系统：分区/无分区卡、根目录簇链、碎片文件均可读取
- 8 个 BMP 资源（4 个分类主图 + 4 个菜品详情素材）预加载到 SDRAM 多块帧缓存，切换无黑屏
- 广告：空闲 20 s 自动进入，AD01-AD04 任意分辨率（宽 320-1024、高 180-1024）双线性缩放居中显示；
  底部半透明天气卡片（天气图标、天气、温度、体感、推荐菜品），内容由后厨天气页设置并经网口下发，
  图标按天气配色（晴天金黄、雨天蓝色等，不随波普颜色变化），上电默认晴天 26 ℃
- 转场：淡入淡出、横向擦除、中心圆形展开；缩略图 2×2 预览选图
- OSD：状态栏、滚动字幕（后厨下发）、参数弹窗、自动轮播进度条、音频波形（颜色可调）
- 音频：AUDIO.PCM 内 6 首背景音乐，随画面自动切换并淡入淡出（音画联动）；
  开机两段转场音效、按键音、后厨接单 / 备餐完成提示音
- 图文点餐：菜品详情（口味、过敏原、主配料等）、购物车、提交订单，售罄菜品禁点

## 操作说明

拨码开关 {SW4 SW3 SW2 SW1}（拨下为 1），数码管前两位显示当前模式号。

| 拨码 | 模式 | K1 | K2 | K3 | K4 |
|---|---|---|---|---|---|
| 0000 | 浏览 | 下一张 | 上一张 | 进入该分类菜单 | 短按自动轮播开/关；长按进入缩略图 |
| 0001 | 亮度 | 增大 | 减小 | | |
| 0010 | 对比度 | 增大 | 减小 | | |
| 0011 | 音量 | 增大 | 减小 | | |
| 0100 | 字幕速度 | 加快 | 减慢 | | |
| 0101 | 自动轮播间隔 5-15 s | 加长 | 缩短 | | |
| 0110 | 波普 / 进度条颜色（10 种） | 下一种 | 上一种 | | |
| 0111 | 背景音乐 | | | 音乐开/关 | |
| 1111 | 提交订单 | | | | 提交购物车到后厨 |

拨到 0001-0111 时立即弹出该参数的当前值；参数模式只在主界面生效。

- 菜品菜单：K1/K2 切换菜品，K3 加入购物车，K4 短按撤销最近一道，K4 长按返回主界面
- 缩略图：K1/K2 移动选框，K3 确认，K4 取消
- 广告：K2 缩小，K3 放大，K4 退出

背景音乐对应：主食 1 暖意相逢、小吃 2 晨光轻语、饮品 3 东方茶香、套餐 4 夜色爵士、
广告 5 午后微风、缩略图 6 灯火归心。

## TF 卡文件

先快速格式化为 FAT32（AUDIO.PCM 需要连续存放），再把下列文件复制到根目录，文件名保持大写 8.3：

| 文件 | 内容 |
|---|---|
| CAT01-CAT04.BMP | 分类主图（主食 / 小吃 / 饮品 / 套餐），1280×720，24 位非压缩 |
| CAT05-CAT08.BMP | 对应分类的菜品详情素材，400×1184，24 位非压缩 |
| AD01-AD04.BMP | 广告海报，24 位非压缩，宽 320-1024（4 的倍数）、高 180-1024 |
| AUDIO.PCM | 6 首背景音乐（单声道 16 bit 48 kHz PCM，文件头为曲目索引） |

## 编译

- TD 6.2 打开 `official_project.al`，依次运行综合、布局布线、生成比特流即可，布局种子已在工程中设为 35
- 约束：`project/constraints/pin.adc`（管脚）、`project/constraints/timing.sdc`（时序与跨时钟域）
- 参考结果：建立时间余量 +0.017 ns，保持时间余量 +0.027 ns；LUT 17956 / 19600

## 目录

| 目录 | 内容 |
|---|---|
| `project/rtl/application` | 媒体调度（扫描、预加载、按键、菜单、广告、购物车） |
| `project/rtl/filesystem`、`protocol` | FAT32 扫描与文件流、BMP 解析、SD 扇区读取 |
| `project/rtl/buffer` | SDRAM 控制与帧缓存读写 |
| `project/rtl/display` | 转场、缩略图、OSD、字库、菜品详情、参数调节、开机动画、广告缩放 |
| `project/rtl/audio` | PCM 播放、曲目控制、音画联动淡入淡出、提示音、按键音 |
| `project/rtl/net` | 千兆以太网 RGMII 与板间链路协议 |
| `project/rtl/integration` | 顶层 `top_tf_hdmi_audio.v` |
| `project/rtl/drivers`、`include` | 按键、数码管、HDMI 物理层、SDRAM 控制器 |
| `project/constraints` | 管脚与时序约束 |
| `project/vendor_ip` | 厂商 IP（PLL、FIFO、SDRAM、HDMI 发送核） |

复用说明：SD 卡 SPI 底层驱动（`sd_card_top`、`sd_card_cmd`、`sd_card_sec_read_write`、
`spi_master`）沿用开发板例程，HDMI 发送核为厂商加密 IP；其余模块为本作品自主设计。
