# 默契食光 —— 基于双 FPGA 的无障碍图文点餐与多媒体展示系统

全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 创新设计赛道 · 选题一（基于安路 EG4S20 的 HDMI 多媒体播放系统）

两块 HX4S20C 开发板（安路 EG4S20BG256）通过千兆网口直连组成前后台系统：前台交互端读取 TF 卡中的图片与音乐，
以 1280×720@60 HDMI 输出图文菜单、广告与背景音乐，顾客无需语音交流即可完成点餐；后厨控制端接收订单，管理接单、
备餐、售罄、标语、天气与营业统计，并把订单进度实时同步回前台。全部逻辑以 Verilog 在 FPGA 中实现，不含处理器。

## 编译环境与结果

- 开发工具：Anlogic TD 6.2，器件 EG4S20BG256
- 打开工程后依次运行综合、布局布线、生成比特流即可，布局种子已在工程中设置

| 工程 | 建立 / 保持时间余量 | LUT | BRAM9K / BRAM32K | DSP |
|---|---|---|---|---|
| 交互端 | +0.017 ns / +0.027 ns | 17956 / 19600 | 60 / 15 | 28 |
| 后厨控制端 | +0.111 ns / +0.022 ns | 17065 / 19600 | 61 / 16 | 29 |

## 主要功能

- 纯硬件 FAT32 文件系统读取 TF 卡 BMP 图片与 PCM 音乐，8 块 SDRAM 帧缓存常驻预加载
- HDMI 1280×720@60 音视频输出，48 kHz 背景音乐随画面同步切换并淡入淡出
- 擦除、淡出淡入、中心展开三种转场与 2×2 缩略图
- 任意分辨率广告图片的双线性自适应缩放
- 亮度、对比度、音量、字幕速度、轮播间隔、波形颜色实时调节与 OSD 显示
- 前台音频波形与后厨 28 段状态变量滤波器组频谱
- 图文菜单（口味、过敏原、主配料）、购物车与一键下单，售罄菜品自动禁点
- 千兆以太网自定义协议：订单、售罄、广告、字幕与天气卡片双板实时同步，断线自动恢复
- 后厨显示列表瓦片界面引擎：订单、菜品、标语、天气、营业统计、链路六个页面
