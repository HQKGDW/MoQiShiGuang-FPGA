# 默契食光 · 后厨控制端

全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道 · 选题一（双板系统的从板）
平台：HX4S20C 开发板（安路 EG4S20BG256），HDMI 1280×720@60 音视频输出。

后厨控制端通过千兆网口直连交互端（工程 `Official_Project`）：接收前台订单，管理接单、
备餐与售罄，向前台下发售罄菜品、广告编号、标语和订单进度字幕。整套界面由 FPGA 内的
瓦片引擎实时绘制（不使用 SDRAM），TF 卡只存放背景音乐。

## 功能一览

- 六个页面：订单工作台、菜品管理（售罄设置）、标语设置、今日天气、营业统计、链路诊断；
  页面切换带擦除 / 中心展开转场
- 今日天气：店员手动设置天气（晴天 / 多云 / 阴天 / 小雨 / 大雨 / 雪天）、温度（-9～40 ℃）
  和湿度（0～100 %），页面左侧为动态天气插画（太阳呼吸光晕与闪烁光芒、云朵漂移、雨丝、飘雪），
  右侧为天气选项、温度条、湿度条、体感与推荐菜品；天气、温度与推荐菜品以卡片形式经网口下发，
  显示在前台广告画面底部（上电默认晴天 26 ℃、湿度 55 %；湿度只在后厨显示）
- 营业统计：完成订单、营业额、售出份数、客单价四张指标卡，各分类销量与菜品销量柱状图、
  热销第一高亮、营业时长；每次进入页面数字与柱状图从零缓动增长
- 订单：最多 4 张卡片，待接单 → 制作中 → 已完成，满单时自动清除最早完成的订单
- 前台联动：售罄菜品前台禁点，标语与订单进度以字幕形式显示在前台，接单 / 备餐完成时前台响提示音
- 频谱：字幕上方 28 段频谱柱状图（28 路状态变量带通滤波器，单乘法器分时计算），随声音跳动
- 音频：TF 卡 AUDIO.PCM 背景音乐（默认第 6 首），新订单 / 开机转场提示音、按键音
- 开机动画：品牌动画 → 自检页 → 中心展开进入工作台

## 操作说明

拨码开关 {SW4 SW3 SW2 SW1}（拨下为 1）。拨到某模式时会立即弹出该模式的当前值。

| 拨码 | 模式 | K1 | K2 | K3 | K4 |
|---|---|---|---|---|---|
| 0000 | 工作 | 下一项 | 上一项 | 对当前项操作（见下） | 短按下一页；长按上一页 |
| 0001 | 亮度 | 增大 | 减小 | | |
| 0010 | 对比度 | 增大 | 减小 | | |
| 0011 | 音量 | 增大 | 减小 | | |
| 0100 | 字幕速度 | 加快 | 减慢 | | |
| 0101 | 前台广告 | 下一张 | 上一张 | | |
| 0110 | 波普颜色（10 种） | 下一种 | 上一种 | 生成一张测试订单 | |
| 0111 | 背景音乐 | 下一首 | 上一首 | 音乐开/关 | |
| 1111 | 订单处理 | 下一张订单 | 上一张订单 | 推进订单状态（见下） | 短按下一页；长按上一页 |

订单状态由 K3 逐步推进：待接单 → 制作中（接单）→ 已完成（备餐完成）→ 删除。
0000 下 K3 的作用：订单页按上面推进订单；菜品页切换售罄 / 在售；标语页把标语应用到前台；
天气页依次切换调节项（天气 → 温度 → 湿度），K1 / K2 为下一种 / 上一种天气、温度加 / 减 1 ℃
或湿度加 / 减 1 %（温度与湿度长按 0.5 s 后连续加减，与亮度调节相同）；
统计页无操作（营业统计断电清零）；链路页清零链路收发计数。1111 在任何页面按 K1/K2/K3 都会先回到订单页，之后与订单页操作相同。

数码管：前两位为模式号，`P` 加页号，最后一位为订单数。
LED0 链路正常、LED1 接收、LED2 发送、LED3 有前台订单等待上板。

## TF 卡

快速格式化为 FAT32 后，把 `AUDIO.PCM`（与交互端同一个文件）复制到根目录。没有 TF 卡时只是没有背景音乐。

## 编译

- TD 6.2 打开 `kitchen_console.al`，依次运行综合、布局布线、生成比特流即可，布局种子已在工程中设为 3
- 约束：`project/constraints/pin.adc`（管脚）、`project/constraints/timing.sdc`（时序与跨时钟域）
- 参考结果：建立时间余量 +0.111 ns，保持时间余量 +0.022 ns；LUT 17065 / 19600
- 界面布局、文字和调色板编译在 `project/rtl/kitchen/*.mif` 显示列表与字库 ROM 中

Flash 固化（TD BitWriter 6.2）：选择 `PROGRAM_FLASH`、Flash 型号 `W25Q16`，加载生成的 `kitchen_console.bit`，
编程并校验后断电重启即可自动运行。

## 目录

| 目录 | 内容 |
|---|---|
| `project/rtl/kitchen` | 状态核心、瓦片合成器、显示、开机动画、提示音、背景音乐、频谱、天气插画 |
| `project/rtl/net` | 千兆以太网 RGMII 与板间链路协议（协议说明见 `kitchen_link.v` 开头） |
| `project/rtl/sd` | SD 卡、FAT32 扫描、PCM 播放（与交互端共用的模块） |
| `project/rtl/shared` | HDMI、按键、参数调节、亮度对比度等通用模块 |
| `project/vendor_ip` | 厂商 IP（PLL、FIFO、HDMI 发送核） |
| `project/constraints` | 管脚与时序约束 |

复用说明：SD 卡 SPI 底层驱动沿用开发板例程，HDMI 发送核为厂商加密 IP；其余模块为本作品自主设计。
